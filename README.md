# Sistema de Vinculación Tec Laguna

## Descripción
Este proyecto es un sistema web desarrollado para la gestión de residencias profesionales y empleos en el Instituto Tecnológico de La Laguna. El sistema permite la administración de convocatorias, gestión de usuarios con diferentes roles (residentes, egresados, empresas, administradores), y facilita la interacción entre los estudiantes y las empresas para procesos de vinculación.

El diseño está orientado a ser modular, seguro, escalable y accesible, con un enfoque en la experiencia de usuario y buenas prácticas en desarrollo web.

## Estructura del Proyecto
- `public`  Archivos públicos accesibles, como HTML, CSS, JS, imágenes.
- `src`  Código backend (PHP, lógica del sistema).
- `config`  Configuraciones generales del sistema.
- `database`  Scripts y migraciones para la base de datos.
- `uploads`  Archivos subidos por usuarios (documentos, fotos).
- `logs`  Registros y logs del sistema.

## Tecnologías utilizadas
